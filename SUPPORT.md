# Support

For reproducible defects or accessibility problems without sensitive information, open a GitHub issue. Include the URL, expected/actual behavior, browser/device, steps, and a privacy-safe screenshot.

For setup questions, read `README.md`, `INSTRUCTIONS.md`, and `DEPLOYMENT.md`, then include the command and full error output in an issue.

Do not use GitHub for medical advice, emergencies, diagnoses, appointments, hospital complaints, patient records, personal health information, or vulnerabilities. Use `SECURITY.md` for private security reporting. For urgent medical help, contact local emergency services or the hospital through its official channels.
