# Code of conduct

We are committed to a respectful, inclusive, harassment-free project. Be considerate, give actionable feedback, respect privacy, and keep discussion focused on improving the website.

Unacceptable behavior includes harassment, discriminatory language, threats, sexualized attention, intimidation, publishing private information, misuse of patient or staff data, and sustained disruption.

Report concerns privately to a TEAM PSMPV repository administrator. Maintainers may remove contributions, restrict participation, or take proportionate action. Reports will be handled as confidentially as practical, and retaliation is prohibited.

This code applies in repository spaces and when representing the project publicly. It is adapted from Contributor Covenant 2.1 principles.
