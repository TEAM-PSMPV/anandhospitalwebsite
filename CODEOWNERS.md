# Code ownership

GitHub requires the canonical rules in [`.github/CODEOWNERS`](.github/CODEOWNERS); it does not enforce `CODEOWNERS.md`. This file is a human-readable pointer.

TEAM PSMPV owns the repository. Changes to automation, Worker code, Cloudflare configuration, or the security policy require TEAM PSMPV review. Branch protection should require code-owner approval on `main`.
